# tariqhattab.github.io

Personal portfolio of **Tariq Hattab**, software engineer in Jeddah, Saudi Arabia.

The whole site is one self-contained page (`index.html`) with every image embedded. It reads like an approval workflow: a request file follows the visitor, each project is signed off with an ink stamp, and the page ends with a decision letter and a QR code that opens WhatsApp. `og.jpg` is the link-preview image used by WhatsApp, LinkedIn and X.
